# Power BI Sales Dashboard

This folder contains the Power BI dashboard created for the Sales Analysis project.

## Dashboard Features

The dashboard provides a visual analysis of:

* Total Sales
* Sales by Product
* Sales by Category
* Sales by Region
* Sales by Customer
* Monthly Sales Performance

## Key Metric

**Total Sales: 771,400**

The dashboard was created using Power BI to transform the sales data into interactive and easy-to-understand visualizations for business decision-making.
